# Firmware v1.2.0

A small release after v1.1.0 (2026-11-08): one fix to the Block level style, and the release itself is now built by GitHub Actions.

Updating from v1.1.0 keeps the unit's settings and its sensor calibration. A unit updating from an older version needs Settings, Advanced, Sensor calibration once, as described in v1.1.0.

## What is new

**Level view**
- The Block style now shows every angle the same way on both sides:
  - level within the level threshold, like the other two styles;
  - the centre and side block in the tilt colour up to three thresholds;
  - past that, the side block alone.

  Before, between one and two thresholds the blocks kept whatever they showed last. A unit coming from level still said level there. The right side also needed five thresholds, not three, before the side block showed alone.

**Building and releases**
- Every change is built by GitHub Actions, and each release is built there from its tag. The firmware reports exactly the release's version.
- A fresh clone of the repository now builds for the ESP32-S3 without extra steps, with the same components the release was tested with.
- The README introduces the project. The hardware is described in `docs/technical_brief.md`.

## Updating a unit

Over Wi-Fi, from the repo on a computer on the unit's network, with this release's OTA package:

```bash
python scripts/ota_host.py --package OpenWeaponMountComputerFirmware-v1.2.0-ota.zip
```

Restart the unit: after its Wi-Fi connects it finds the update, and Settings shows "Update available" at the top. Units already on v1.2.0 are not offered it.

## Known limits

- Updates come over plain HTTP from a host on the local network and are not signed; the image's checksum rejects a damaged download. Run the host only on a network you trust.
- The update check compares major, minor and patch only: builds after v1.2.0 that are not tagged read as 1.2.0 and are not offered to a 1.2.0 unit (`--force` on the host offers them).
- The second update source, a central server, is a placeholder and not enabled.
- The Power page still offers 4.35 V and 4.4 V charge voltages. They are above the Vapcell T9's 4.20 V, so keep 4.2 V for that cell.
- Right after power-on, the level can read up to about 0.15° off while the sensor warms up; it settles within about 3 minutes.

## Files

- `OpenWeaponMountComputerFirmware-v1.2.0.bin`: the firmware (the image an update installs).
- `OpenWeaponMountComputerFirmware-v1.2.0-ota.zip`: the OTA package: the update's manifest (version v1.2.0 and the note the unit shows) and the firmware, served by `scripts/ota_host.py --package`.
- `bootloader.bin`, `partition-table.bin`, `ota_data_initial.bin`: with the firmware, all a unit needs over USB.

Flashing over USB with esptool keeps the unit's settings (the settings partition is not written); the unit then starts from the first app slot:

```bash
python -m esptool --chip esp32s3 -p <port> write_flash --flash_mode dio --flash_freq 80m --flash_size 16MB 0x0 bootloader.bin 0x8000 partition-table.bin 0x10000 ota_data_initial.bin 0x320000 OpenWeaponMountComputerFirmware-v1.2.0.bin
```
