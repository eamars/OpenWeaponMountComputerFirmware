# Firmware v1.1.0

The second release since v1.0.0 (2026-11-07). How each part was decided and checked on the unit is in its ADR under [docs/developments_plans](../developments_plans/README.md).

**After updating, run Settings, Advanced, Sensor calibration once.** The old Tare is gone: at the first start the unit deletes the tare stored in its sensor, and until it is calibrated the level reads up to about a degree off.

## What is new

**Sensor calibration** (ADR-011)
- Replaces Tare. It needs no compass and no level table: stand the unit on its bottom edge (rotation 0) on a flat, firm surface, turn it around on the same spot, then turn it back. The two placements cancel the surface's tilt; the third checks that it repeats.
  - A ring shows how far a turn still has to go.
  - Beeps tell you when each placement is taken, and when to move it.
  - If the unit is bumped during a placement, the screen asks you to put it back.
  - The result shows the unit's offset, the surface's tilt and the repeat. Saving also clears the rifle zero.
- The level now measures cant from gravity in the sensor's own frame. The compass direction the unit faces no longer matters.
- The sensor no longer re-calibrates its accelerometer by itself, so the zero stays put. Handling the unit moved it by 0.02°.

**Level view** (ADR-010)
- A third level style, Chevrons: full-screen moving chevrons in the tilt colour on black, pointing the way to turn the rifle, faster the more it cants, and the whole screen in the level colour when level. Choose it under Level, Level style.

**Battery and power** (ADR-009)
- The unit powers itself off at 5% battery, instead of running the cell down to 2.6 V.
- The 3.3 V rail's under- and over-voltage protection is back on.
- The board temperature (TH1) reads correctly and shows on the Power page as "Board".
- Charging stops at 100 mA, the Vapcell T9's own cut-off.
- New units default to a 1000 mA USB input and power off after 5 hours idle. Saved settings are kept.
- While idle the unit really sleeps between stages:
  - the screen stops redrawing and the panel sleeps;
  - the processor sleeps automatically (99% of idle time asleep on battery);
  - it stays awake while USB power is in.
- Waking by touch and button is quicker, and the level moves within about 0.12 s of a wake.
- Moving the unit counts as use, so the screen no longer goes dark in your hand. It still never sleeps while the timer runs.

**Dope tile**
- In portrait, the Kestrel status and the Pull button share the row.

## Updating a unit

Over Wi-Fi, from the repo on a computer on the unit's network, with this release's OTA package (no build needed):

```bash
python scripts/ota_host.py --package OpenWeaponMountComputerFirmware-v1.1.0-ota.zip
```

Or from your own build of the `v1.1.0` tag:

```bash
python scripts/ota_host.py --note-file docs/releases/v1.1.0_note.txt
```

Restart the unit: after its Wi-Fi connects it finds the update, and Settings shows "Update available" at the top. Units already on v1.1.0 are not offered it. Over USB: `idf.py -p <port> flash`.

Then run Sensor calibration once (see above).

## Known limits

- Updates come over plain HTTP from a host on the local network and are not signed; the image's checksum rejects a damaged download. Run the host only on a network you trust.
- The update check compares major, minor and patch only: builds after v1.1.0 that are not tagged read as 1.1.0 and are not offered to a 1.1.0 unit (`--force` on the host offers them).
- The second update source, a central server, is a placeholder and not enabled.
- The Power page still offers 4.35 V and 4.4 V charge voltages. They are above the Vapcell T9's 4.20 V, so keep 4.2 V for that cell.
- Right after power-on, the level can read up to about 0.15° off while the sensor warms up; it settles within about 3 minutes.

## Files

- `OpenWeaponMountComputerFirmware-v1.1.0.bin`: the firmware (the image an update installs).
- `OpenWeaponMountComputerFirmware-v1.1.0-ota.zip`: the OTA package: the update's manifest (version v1.1.0 and the note the unit shows) and the firmware, served by `scripts/ota_host.py --package`.
- `bootloader.bin`, `partition-table.bin`, `ota_data_initial.bin`: with the firmware, all a unit needs over USB.

Flashing over USB with esptool keeps the unit's settings (the settings partition is not written); the unit then starts from the first app slot:

```bash
python -m esptool --chip esp32s3 -p <port> write_flash --flash_mode dio --flash_freq 80m --flash_size 16MB 0x0 bootloader.bin 0x8000 partition-table.bin 0x10000 ota_data_initial.bin 0x320000 OpenWeaponMountComputerFirmware-v1.1.0.bin
```
